## 📖 How Does It Work?

Here's a simple explanation:

- Your game normally reads graphics and character models from game files.
- marvelrivals-galacta acts as a "virtual bridge" between the game and your custom skins.
- When you select a new look, the app temporarily shows that skin to the game in real time.
- When you exit, everything goes back to normal.

Think of it like changing the wallpaper on your phone — the phone system isn't changed, only what you see.
